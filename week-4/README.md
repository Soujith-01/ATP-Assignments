# Week 4 - HTML & CSS Fundamentals

## Overview
This folder contains HTML and CSS assignments focused on building foundational web development skills. Topics include basic HTML structure, semantic markup, CSS styling, Flexbox layouts, HTML tables, and introduction to Tailwind CSS framework.

## Folder Structure

### 1. Assignment1.html
   - Basic HTML document structure
   - Introduction to semantic HTML elements
   - Contains paragraphs, headings, and unordered lists
   - Focus on HTML structure without styling
   - Concepts: DOCTYPE, semantic tags (p, h1, ul, li)

### 2. Assessment/ - Styling & Media
   
   #### Assignment2.html
   - More complex HTML page with images and content
   - Demonstrates linking to external CSS files
   - Includes:
     - Headings and paragraphs
     - Images with alt text
     - Ordered and unordered lists
     - Navigation links
     - Horizontal rule divider
   - Concepts: Image embedding, links, semantic structure
   
   #### styles.css
   - CSS styling for Assignment2.html
   - Basic styling rules and formatting
   - Concepts: Selectors, properties, layout basics

### 3. flexAssignment/ - CSS Flexbox Layout
   
   #### index.html
   - HTML layout designed for Flexbox demonstration
   - Employee card display structure
   - Container and card elements
   
   #### styles.css
   - Flexbox implementation with:
     - `display: flex` for layout
     - `gap` property for spacing between items
     - `flex-grow` for responsive sizing
     - Box shadow for card styling
     - Border radius for rounded corners
     - Image and text styling
   - Concepts: Flexbox, responsive design, card layouts, spacing

### 4. tableAssignment1/ - HTML Tables (Basic)
   
   #### index.html
   - Basic HTML table structure
   - Table with thead (table header) section
   - Column spanning using `colspan` attribute
   - Multi-level headers
   
   #### styles.css
   - CSS styling for table presentation
   - Concepts: Table structure, colspan, table styling


### 5. tableAssignment2/ - HTML Tables (Advanced)
   
   #### index.html
   - Advanced HTML table assignment
   - Complex table layouts with multiple rows and columns
   
   #### styles.css
   - Enhanced table styling and formatting
   - Concepts: Table styling, formatting, alignment

### 6. tailWindProject/ - Tailwind CSS Framework
   
   #### package.json
   - Tailwind CSS project configuration
   - Dependencies: `@tailwindcss/cli`, `tailwindcss`
   - Configured as CommonJS project
   - Framework: Utility-first CSS framework
   
   #### src/
   - Contains Tailwind project files:
     - input.css - Source CSS with Tailwind directives
     - output.css - Generated CSS file (compiled)
     - 1.html - HTML file using Tailwind classes
     - reactTask1.html - React-related HTML component template
     - reactTask2.html - Additional React-related HTML template
   
   - Concepts: Utility-first CSS, class-based styling, rapid development


##  Key Concepts Covered

- HTML Fundamentals:
  - Document structure (DOCTYPE, html, head, body)
  - Semantic elements (h1-h6, p, ul, ol, li)
  - Images and media (img, alt text)
  - Links and navigation (a tags)
  - Tables (table, thead, tbody, tr, th, td, colspan)

- CSS Styling:
  - Selectors (element, class, ID)
  - Properties (color, background, margin, padding)
  - Box model and sizing
  - Border radius and shadows
  - Text alignment and formatting

- Layout Techniques:
  - Flexbox (display: flex, gap, flex-grow, justify-content)
  - Responsive design principles
  - Card-based layouts
  - Table layouts

- Frameworks & Tools:
  - Tailwind CSS - utility-first approach
  - CSS preprocessing
  - External stylesheet linking
